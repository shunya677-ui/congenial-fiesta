# Анализ медианной зарплаты в России (2010–2024)

Проект выполняет загрузку данных о медианной зарплате, визуализацию, статистический анализ и прогнозирование методом скользящей средней.

## Участники
- Student Main (владелец) – общий интерфейс, загрузка данных
- Dev One – таблица, расчёт процентов роста
- Dev Two – график и прогноз

## Запуск
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите: `python src/main.py`
3. Загрузите CSV-файл с данными (пример в папке `data/`)

## Источники данных
- Росстат (медианная зарплата 2019–2024)
- Синтетические данные на основе средних зарплат для более ранних лет

## Функциональность
- Таблица с сортировкой
- График зарплат с выбором периода
- Прогноз по скользящей средней с настраиваемыми параметрами
- Экспорт графиков в PNG, PDF, SVG

## Структура репозитория
- `main` – финальная версия
- `dev` – ветка разработки
- `feature/...` – ветки участников
